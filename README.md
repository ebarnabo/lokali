# Lokali

Application web de circuit court de proximité pour la Guadeloupe.

Connecte les habitants aux producteurs et commerçants locaux (marchés, fermes, épiceries 100 % lokal).

## Fonctionnalités

- Recherche et filtres produits
- Carte des points de vente
- Détail stocks + réservation retrait
- Entraide (surplus / besoins / covoiturage)
- Inscription commerçants (abonnement mensuel, promo grève pour commerces validés)

## Lancer

```bash
npm install
npm run dev
```

Design : Inter, palette verte + rouge drapeau indépendantiste, formes arrondies, animations légères Framer Motion.
